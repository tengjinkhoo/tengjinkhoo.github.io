# Teng Jin Khoo Portfolio

This repo is set up as a static portfolio site for GitHub Pages.

## Files

- `index.html`: page content (about, experience, work highlights, skills, contact)
- `styles.css`: visual design and responsive layout
- `script.js`: mobile menu, section highlight, reveal animation, copy-email button
- `assets/resume/Teng_Jin_Khoo_Resume.pdf`: downloadable resume
- `assets/recommendation/Khoo_Teng_Jin_Recommendation_Letter.pdf`: recommendation letter with in-page preview

## Publish on GitHub Pages

1. Push this repository to GitHub.
2. Go to `Settings > Pages`.
3. Under "Build and deployment", select:
   - Source: `Deploy from a branch`
   - Branch: `main` (or your default branch), folder `/ (root)`
4. Save and wait for deployment.
5. Your site will be available at:
   - `https://<your-username>.github.io/<repo-name>/`
   - Or `https://<your-username>.github.io/` if this is your username repo.

## Quick edits

- Update experience/project text in `index.html`.
- Update LinkedIn/email in the contact section in `index.html` and `script.js`.
- Replace resume file in `assets/resume/` and keep the same filename, or update the link in `index.html`.
